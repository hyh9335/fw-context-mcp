# Decision Protocol

No voting. Each decision must record:
question, options, supporting facts, opposing facts, assumptions, cost of being wrong, reversibility, decision, confidence, revisit trigger, dissenters.

Mandatory decisions:
D01 fw-context role in final system
D02 minimum fw-context trust bar before MVP
D03 variant/context family before MVP?
D04 callback propagation MVP-critical?
D05 dead-code/vector MVP-critical or conditional?
D06 exact/pagination/query-honesty requirements
D07 first end-to-end fault-discovery scenario
D08 MVP ground truth/evaluation method
D09 next implementation wave scope
D10 explicit non-goals

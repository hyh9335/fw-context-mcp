# Debate Protocol

R1: A1–A8 are isolated and may not see each other's reports.

R3 pairings:
- A1 ↔ A5
- A2 ↔ A4
- A3 ↔ A6
- A5 ↔ A8
- A7 critiques every strategy

Each must state:
- opponent's 3 strongest claims;
- strongest evidence for each;
- what changed in my own view;
- remaining unresolved question;
- strongest falsifier for my current position.

After scenario/red-team, A2/A3/A4/A5/A6/A8 revise positions; A7 retains unresolved objections. No forced consensus.

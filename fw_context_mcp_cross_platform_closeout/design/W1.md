# W1 design seed

Target a platform-independent service boundary.

Suggested interfaces:
- ProcessService: is_alive, identify, terminate
- InterProcessLock: acquire/release/timeout
- FileSystemCapabilities: safe_open, symlink/socket capabilities
- ControlTransport: create/connect endpoint

Preferred layout if compatible:
`fw_context_mcp/platform/{base,posix,windows,capabilities}.py`

Rules:
- no fake host fcntl shim
- POSIX backend may use fcntl,/proc,AF_UNIX,signals
- Windows backend may use LockFileEx/msvcrt, Win32 process APIs, Windows-supported endpoint
- business/index modules call interfaces, not raw primitives
- avoid scattered `if os.name == "nt"`
- SQLite busy_timeout alone is not lifecycle-wide interprocess exclusion
- internally-created subprocess decoding must not depend on global PYTHONUTF8

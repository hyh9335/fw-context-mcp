# W1 tests
Backend contract on both Windows and WSL:
- second process blocked by held lock
- acquires after release
- acquires after holder crash
- concurrent index writers never overlap protected critical section
- timeout deterministic
- Windows import succeeds without fcntl shim
- WSL uses real fcntl on Linux fs
- daemon/control endpoint create/ping/stop/restart/stale cleanup
- no unconditional O_NOFOLLOW assumption
